# 검수 결과

## 확인 완료 (정적 검수 및 실행 테스트)
- HTML 내 메뉴 4개, 섹션 앵커, ID 중복 없음, CSS/JS 상대 경로 존재 확인.
- Node.js 22에서 main.js, data.js, images-fallback.js, 이미지 생성 스크립트 문법 검사 통과.
- 이미지 생성 스크립트를 임시 폴더에서 실제 실행: 이미지 추가·삭제·교체 반영, 한글/공백 파일명, 대문자 확장자, SVG/GIF/WEBP, 숨김 파일·지원하지 않는 확장자 제외, 로컬 fallback 갱신 확인.
- GitHub Actions YAML 구문 파싱 및 build/deploy 구조 확인. 배포 자체를 실행한 것은 아님.

## 구현했으나 브라우저 실동작 검수 미완료
검수용 Chromium의 보안 정책이 file:// 및 로컬 HTTP 접속을 차단했습니다. 따라서 메뉴 스크롤 및 활성화, 모바일 레이아웃, 모달/라이트박스, 필터/더보기, 키보드/터치 스와이프, 이미지 로딩·슬라이드, 애니메이션의 실제 렌더링 및 런타임 오류 여부는 사용자의 브라우저에서 확인해야 합니다. JS 문법 검사 통과는 브라우저 런타임 무오류를 보증하지 않습니다.

## 공개 전 확인 필요
- 실제 공식 로고·사진·캐릭터·색상표 원본 미제공: 초기 화면은 임시 색상·텍스트 워드마크·추상적 대체 영역입니다. 실제 브랜드 사진으로 오인될 이미지를 삽입하지 않았습니다.
- 공식 연락처 미제공: 입력란 비워 둠. 실제 공개할 링크를 data.js에 입력하십시오.
- 사업 진행 상태 초기 분류와 문구: 공개 전 운영자가 검토하십시오.
- 실제 GitHub 저장소 및 Pages 권한 설정, 워크플로 실행 결과, 배포 URL은 확인하지 않았습니다.
- 개인정보·비공개 사업 자료가 없는 승인된 이미지만 images/에 넣으십시오.
